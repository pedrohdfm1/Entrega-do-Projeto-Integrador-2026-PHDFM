#  Análise de Burnout e Saúde Mental em Estudantes

##  Tema do Projeto
Análise de dados sobre saúde mental e burnout em estudantes, com foco na identificação de padrões, causas e possíveis soluções para melhorar o bem-estar antes da entrada no mercado de trabalho.
